みよこみ 企業チャンネル利用規約

合同会社JProduct

第1条（目的及び適用）

  1. 本規約は、合同会社JProduct（以下「当社」といいます。）が提供するアプリケーション「みよこみ」（以下「本サービス」といいます。）において、企業、店舗、団体、個人事業主その他事業として活動する者（以下「掲載事業者」といいます。）が企業チャンネルを開設し、運用する場合の利用条件を定めるものです。
  2. 掲載事業者は、本規約に同意したうえで、事業上の目的で本サービスを利用するものとします。掲載事業者のために申込み又は操作を行う担当者は、掲載事業者を代理して本規約に同意し、本契約を締結する正当な権限を有するものとします。
  3. 当社が本サービス内又は当社ウェブサイト上で掲示する掲載基準、操作上の案内その他の個別規定は、本規約の一部を構成します。個別規定において本規約と異なる定めを置くことが明示されている場合は、当該個別規定が優先します。
  4. 掲載事業者の担当者が一般ユーザーとして本サービスを利用する場合には、別途定める一般ユーザー向け利用規約が適用されます。企業チャンネルの開設及び運用に関しては、本規約が優先して適用されます。

第2条（申込み、登録及び審査）

  1. 企業チャンネルの開設を希望する者は、法人名又は屋号、所在地、電話番号、代表者氏名、事業ジャンル、担当者の氏名及び連絡先その他当社所定の情報を登録し、当社所定の方法により申込みを行うものとします。
  2. 申込者は、登録情報が真実、正確かつ最新であることを保証し、登録情報に変更が生じた場合は、速やかに当社所定の方法により変更するものとします。当社は、審査に必要な範囲で、資料の提出又は追加の説明を求めることがあります。
  3. 当社は、申込みについて、本サービスの目的、利用者の安全、掲載内容の適法性及び運営上の必要性等を踏まえて審査します。当社は、次のいずれかに該当すると合理的に判断した場合、登録を承認せず、又は承認後にこれを取り消すことができます。
    1. （1）子育て世代向けのコミュニティとして不適切な業種又は内容である場合（性風俗関連営業、賭博、連鎖販売取引、宗教上の勧誘、高額な情報商材の販売その他当社が別途定める掲載基準に該当する場合を含みます。）
    2. （2）登録情報に虚偽、誤記又は重要な記載漏れがある場合
    3. （3）申込みを行った者に、掲載事業者を代理する権限がない場合
    4. （4）過去に本規約、一般ユーザー向け利用規約又は個別規定に違反したことがある場合
    5. （5）第15条に定める反社会的勢力に該当し、又はこれに関与していると認められる場合
    6. （6）その他、登録を認めることが本サービスの安全又は運営上適当でないと当社が合理的に判断した場合
  4. 当社は、審査結果を申込者に通知します。承認しない場合は、可能な範囲で理由を付して通知しますが、審査の詳細な過程又は判断基準を開示する義務を負いません。申込者は、登録内容を修正したうえで再度申請することができます。
  5. 審査の承認は、企業チャンネルの掲載可否についての判断であり、掲載事業者の商品、サービス、活動内容又は信用を当社若しくは三好市が推奨し、保証し、又は認定するものではありません。

第3条（契約の成立及び企業チャンネルの管理）

  1. 当社による審査の承認後、申込者が第4条に定める決済を完了した時点で、当社と掲載事業者との間に企業チャンネルの利用契約（以下「本契約」といいます。）が成立し、企業チャンネルが公開されます。
  2. 掲載事業者は、当社の承認を受けたうえで、複数の企業チャンネルを開設することができます。各企業チャンネルには、第4条に定める料金が適用されます。
  3. 当社は、掲載事業者の申請に基づき、本部アカウントに複数の企業チャンネルの管理権限を付与し、支店又は店舗のアカウントには当該支店又は店舗に係る企業チャンネルのみの管理権限を付与することができます。
  4. 企業チャンネルの管理権限を有するアカウントの追加、変更及び削除は、当社所定の方法により行います。掲載事業者は、権限の付与範囲を適切に管理し、担当者の異動、退職その他権限を変更すべき事情が生じた場合は、直ちに必要な手続を行うものとします。
  5. 投稿は下書きとして保存することができ、掲載事業者が公開の操作を完了した時点で一般ユーザーに表示され、プッシュ通知その他本サービスの仕様に応じた通知の対象となります。下書きの状態では一般ユーザーに公開されません。

第4条（料金、支払及び自動更新）

  1. 企業チャンネルの利用には、有料プランの契約を必要とします。料金は、次のとおりです（いずれも税込）。
    プラン料金
    企業チャンネル1チャンネルにつき 1,650円／月（税込）
  2. 契約期間は1か月とします。掲載事業者が次回更新日の前日までに解約しない限り、本契約は同一の期間で自動的に更新されます。
  3. 2チャンネル目以降の追加チャンネルは月額契約とし、基本となる企業チャンネルのプランとは別に、チャンネルごとに料金が発生します。
  4. 支払方法は、当社が指定する決済代行会社（Stripe, Inc.）を通じたクレジットカード決済とします。初回の利用料金は、当社による審査の承認後、有料プランの申込みを行う際に決済されます。更新後の利用料金は、毎月の応当日に決済されます。
  5. 掲載事業者は、有効な支払情報を登録し、常に最新の状態に保つものとします。決済が完了しない場合であっても、既に発生した利用料金の支払義務は消滅しません。
  6. 本サービスの利用に必要な端末、通信機器、インターネット接続及び通信費は、掲載事業者の責任と費用で準備するものとします。
  7. サービスの性質上、提供開始後の返金及び契約期間途中の解約による日割り返金又は残期間分の返金は行いません。ただし、第12条第4項に定める場合その他当社の責めに帰すべき事由により返金を行う場合は、この限りではありません。
  8. 当社は適格請求書発行事業者に登録していないため、適格請求書（インボイス）を発行することができません。掲載事業者は、この点を了承したうえで申し込むものとします。
  9. 当社が料金を改定する場合、原則として改定日の30日前までに、本サービス内の告知又は登録された連絡先への通知により周知します。改定後の料金は、周知後最初に到来する更新日から適用されます。掲載事業者は、改定に同意しない場合、当該更新日の前日までに解約することができます。

第5条（アカウントの管理）

  1. 掲載事業者は、自己の責任において、企業チャンネルの管理権限を有するアカウント、メールアドレス及びパスワードを適切に管理し、第三者に貸与、譲渡、名義変更又は売買してはなりません。
  2. 管理権限を有するアカウントを用いて行われた操作は、当社に故意又は過失がある場合を除き、掲載事業者による操作とみなします。掲載事業者は、担当者その他管理権限を付与した者の行為について責任を負います。
  3. アカウントの不正利用、認証情報の漏えいその他安全上の問題を認識した場合、掲載事業者は、直ちにパスワードの変更その他必要な措置を講じ、当社に連絡するものとします。
  4. アカウントの管理不十分又は第三者による不正利用により生じた損害については、当社に故意又は過失がある場合を除き、掲載事業者が責任を負うものとします。

第6条（企業チャンネルの運用及び掲載内容）

  1. 掲載事業者は、当社が管理権限を付与した企業チャンネルにおいてのみ、自らの事業、商品、サービス、イベント、地域活動その他子育て世代に関連する情報を発信することができます。
  2. 掲載事業者は、掲載内容を正確かつ最新の状態に保ち、価格、申込条件、提供条件、問い合わせ先、注意事項その他一般ユーザーの判断に重要な事項を、分かりやすく表示するものとします。
  3. 掲載事業者は、掲載内容について、景品表示法、医薬品医療機器等法、健康増進法、特定商取引法、著作権法、商標法、個人情報保護法その他適用される法令及び業界基準を遵守するものとします。
  4. 掲載事業者は、次の行為をしてはなりません。
    1. （1）虚偽、誇大又は一般ユーザーに誤認を与える表示を行うこと
    2. （2）商品又はサービスの効能、効果、安全性、実績等について、客観的な根拠なく断定的な表現を用いること
    3. （3）第三者の著作権、商標権、肖像権、プライバシーその他の権利を侵害する内容を掲載すること
    4. （4）本人又は保護者の同意なく、個人を特定し得る情報又は子どもの顔が明確に判別できる写真等を掲載すること
    5. （5）わいせつ、暴力的、公序良俗に反する内容又は子どもの心身に有害な内容を掲載すること
    6. （6）本サービスの趣旨と関係のない広告を反復し、又はスパムに該当する投稿を行うこと
    7. （7）一般ユーザーが希望していない個別の勧誘、営業連絡又は外部サービスへの誘導を行うこと
    8. （8）宗教上の勧誘、選挙運動その他の政治的勧誘、マルチ商法、ネットワークビジネスその他これらに類する勧誘を行うこと
    9. （9）当社又は三好市が掲載事業者の商品、サービス又は活動を推奨、保証又は認定していると誤認させる表示を行うこと
    10. （10）本サービスへの不正アクセス、プログラムの解析若しくは改変、過度な負荷を与える行為その他本サービスの運営を妨げる行為を行うこと
    11. （11）その他、本サービスの目的若しくは安全を害し、又は企業チャンネルへの掲載が不適切であると当社が合理的に判断する行為
  5. 掲載事業者が公開した内容についての責任は、掲載事業者が負うものとします。当社は、掲載内容の適法性、正確性、完全性又は最新性を保証しません。
  6. 当社は、本規約若しくは掲載基準への適合性の確認、通報への対応、権利侵害の防止又は本サービスの安全確保のために必要な範囲で、掲載内容を確認し、修正若しくは削除を求め、又は第10条に定める措置を講ずることができます。
  7. 当社は、本サービスの運営上必要な範囲で、企業チャンネルの名称、掲載順序、分類、表示方法その他画面上の構成を変更することがあります。

第7条（イベント及び一般ユーザーとの取引）

  1. 掲載事業者がイベント情報を掲載する場合、主催者、開催日時、場所、対象者、参加条件、申込方法、参加費、キャンセル条件、問い合わせ先その他参加の判断に必要な事項を、正確かつ分かりやすく表示するものとします。
  2. 一般ユーザーによる「参加したい」等の登録、ブックマーク又はリマインド設定は、参加予定を管理する機能であり、掲載内容に明示がない限り、イベントへの正式な申込み、予約又は参加枠の確保を意味しません。
  3. イベントの実施、内容の変更若しくは中止、参加者の安全管理、参加費の収受若しくは返金、商品若しくはサービスの提供その他掲載事業者と一般ユーザーとの間の取引は、両当事者の間で行われるものとし、当社は当該取引の当事者となりません。
  4. イベント終了後に写真、参加者の感想その他の開催レポートを掲載する場合、掲載事業者は、必要な同意を取得し、個人又は子どもが不当に特定されないよう配慮するものとします。
  5. 一般ユーザーからの問い合わせ、苦情、返品、返金、事故その他掲載事業者の商品、サービス又はイベントに関する問題は、掲載事業者が自己の責任と費用で対応し、解決するものとします。

第8条（知的財産権及び掲載データ）

  1. 本サービスを構成するプログラム、デザイン、ロゴ、文章、画像、データベースその他のコンテンツに関する著作権、商標権その他の知的財産権は、当社又は正当な権利者に帰属します。
  2. 掲載事業者が企業チャンネルに掲載した文章、画像その他の情報（以下「掲載データ」といいます。）に関する権利は、掲載事業者又は正当な権利者に帰属します。
  3. 掲載事業者は当社に対し、本サービスの提供、表示、配信、通知、保存、バックアップ、検索、不具合対応、安全確保及び機能改善に必要な範囲で、掲載データを無償かつ非独占的に利用することを許諾するものとします。
  4. 当社が本サービス外の広告、広報又は事例紹介の目的で掲載データを利用する場合は、あらかじめ掲載事業者の同意を得るものとします。
  5. 掲載事業者は、掲載データについて必要な権利を有し、又は権利者の許諾を得ていることを保証します。掲載データに関して第三者から権利侵害その他の請求がなされた場合、掲載事業者は、自己の責任と費用でこれに対応するものとします。

第9条（一般ユーザーの情報及び個人情報の取扱い）

  1. 企業チャンネルの管理画面その他本サービス上で掲載事業者に表示される一般ユーザーの情報は、本サービスの仕様に応じて表示されるニックネーム、投稿内容、リアクション、イベントの参加予定その他各機能の利用に伴う情報に限られます。当社は、一般ユーザーのメールアドレス、お子さんの生年月日、居住地区その他の登録情報を掲載事業者に提供しません。
  2. 掲載事業者は、本サービスを通じて知り得た一般ユーザーの情報を、企業チャンネルの運用及び本サービス内での適切な対応に必要な範囲を超えて利用してはなりません。また、当該情報を抽出若しくは収集して名簿等を作成し、第三者に提供し、又は本サービス外の営業若しくは勧誘に利用してはなりません。
  3. 掲載事業者がイベントの申込み、商品の購入、問い合わせその他本サービス外の手続により一般ユーザーから個人情報を直接取得する場合、掲載事業者は、自らの責任で利用目的その他必要な事項を明示し、個人情報保護法その他の法令及び自らが定めるプライバシーポリシーに従って適切に取り扱うものとします。
  4. 掲載事業者は、一般ユーザーの情報について、漏えい、滅失、毀損又は不正利用を防止するために必要かつ適切な安全管理措置を講じます。漏えい等が発生し、又はそのおそれがあることを認識した場合は、直ちに当社に連絡し、必要な対応に協力するものとします。
  5. 当社による個人情報の取扱いについては、別途定めるプライバシーポリシーによるものとします。

第10条（掲載の停止、利用制限及び契約解除）

  1. 当社は、掲載事業者が次のいずれかに該当すると合理的に判断した場合、掲載内容の削除若しくは非表示、企業チャンネルの非公開若しくは休眠、管理権限の停止、登録の取消し又は本契約の全部若しくは一部の解除を行うことができます。
    1. （1）本規約又は個別規定に違反した場合
    2. （2）登録情報に虚偽があり、又は重要な変更の届出を怠った場合
    3. （3）掲載内容が法令に違反し、第三者の権利を侵害し、又は一般ユーザーの安全を害するおそれがある場合
    4. （4）決済が失敗し、その状態が14日以上解消されない場合その他利用料金の支払を怠った場合
    5. （5）アカウントの不正利用、情報漏えいその他本サービスの安全を害する事由が生じた場合
    6. （6）第15条に違反した場合
    7. （7）当社が是正又は確認のために行った連絡に対し、合理的な期間内に回答しない場合
    8. （8）その他、本サービスの安全、信用又は運営を維持するために措置が必要であると当社が合理的に判断した場合
  2. 緊急性が高い場合、法令上必要な場合又は違反の性質上是正が困難な場合、当社は、事前の通知又は催告を行うことなく前項の措置を講ずることができます。それ以外の場合は、可能な範囲で是正を求める通知を行います。
  3. 掲載事業者の責めに帰すべき事由により本条の措置が講じられた場合、当社は受領済みの利用料金を返金しません。
  4. 掲載事業者は、本条の措置に異議がある場合、第20条の窓口に申し出ることができます。当社は、申出の内容を確認し、合理的な期間内に回答します。
  5. 本条に基づく措置により掲載事業者に損害が生じた場合であっても、当社に故意又は過失がある場合を除き、当社は責任を負いません。
  6. 本契約の解除又は終了前に発生した利用料金の支払義務、損害賠償義務その他性質上存続すべき義務は、本契約の終了後も存続します。

第11条（解約及びデータの取扱い）

  1. 掲載事業者は、Stripeカスタマーポータルその他当社所定の方法を通じて、企業チャンネルごとにいつでも解約の手続を行うことができます。解約の効力は、次回更新日に生じ、それまでは企業チャンネルを利用することができます。
  2. 契約期間の途中で解約の手続を行った場合であっても、日割り返金又は残期間分の返金は行いません。
  3. 解約、決済の不履行その他の理由により企業チャンネルが休眠となった場合、当該チャンネルは一般ユーザーに公開されなくなります。当社は、チャンネル及び過去の掲載データを保持し、再度の契約により復元できる状態とすることがあります。
  4. 掲載事業者が企業チャンネル及び掲載データの削除を希望する場合、第20条の窓口へ申し出るものとします。当社は、申出を受けてから30日を目安として削除します。ただし、法令に基づき保存する義務のある情報、取引の記録、紛争対応に必要な情報及びバックアップについては、必要な期間保存することがあります。
  5. 当社は、解約又は休眠の状態が2年を超えて継続した場合、あらかじめ登録された連絡先に通知したうえで、企業チャンネル及び掲載データを削除することができます。
  6. 企業チャンネルの解約又は削除は、担当者が一般ユーザーとして保有するアカウントの退会を意味しません。一般ユーザーとしての退会は、一般ユーザー向け利用規約に従って別途行うものとします。
